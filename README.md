# Character Skill

一个可重复使用的原创人物提示词 Skill，根据人物参考图和文字要求生成可直接用于图像生成模型的单幅人物提示词。

## 功能

- 标准 Skill 文件名为 `SKILL.md`；
- 默认生成横屏 16:9、8K 高清的人物图；
- 默认使用半身人物近景、85mm 人像镜头、浅景深和面部清晰对焦；
- 按年龄、身份、动作和环境匹配脸型、五官、肤质、皱纹、光线与表情；
- 肤质分析包含单一主状态、区域纹理、克制瑕疵、高光分布、光线适配和表情关系；
- 用户未描述衣着时，直接省略衣着段落；描述衣着时，仅保留必要特征；
- 默认使用干净、纯净、均匀的白色背景；
- 输出一段精简、可直接复制的中文提示词，并附少量关键负面提示词；
- 加入原创角色、独立视觉设计和非直接复制现有作品的描述。

## 安装与使用

本项目仅包含 Markdown Skill 规则，不依赖 Python、Node.js 或第三方包。将 `SKILL.md` 放入支持 Skill 或自定义提示词的 AI 工具中并启用，然后提供人物参考图和人物要求即可。

示例输入：

```text
生成一位 55 岁母亲，气质温和、可靠，真实摄影风格。
```

Skill 会根据年龄自动匹配更明显的眼角、额头、法令和嘴角纹理，以及适度的皮肤松弛、色斑和骨骼感；不会机械套用年轻人物的肤质描述。
