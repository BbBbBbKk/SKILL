# Character Skill

可重复使用的中文提示词 Skill，根据人物参考图和用户指定视图生成角色设定图提示词。

## 1. 项目解决什么问题

将人物角色设定图中关于视图选择、宫格数量、人物一致性、画幅、背景和画质的重复描述整理为统一规则，避免模型擅自增加不需要的视图。

## 2. 主要功能

- 提取参考图中的人物主体。
- 保持人物身份、脸部特征、发型、服装、配饰、色彩和材质一致。
- 支持正面、严格 90 度侧面、背面和正脸面部特写。
- 根据视图数量自动生成二宫格、三宫格或四宫格。
- 仅生成用户明确要求的视图。
- 支持自定义画幅、背景、风格、画质和排列顺序。
- 默认使用横向 16:9、纯灰色影棚背景和 4K 高清画质。
- 自动加入避免变形、细节不一致、裁切、文字和水印的负面约束。

## 3. 安装方法

本项目仅包含 Markdown 提示词规则，不依赖 Python、Node.js 或第三方包。将 `character-skill.md` 放入支持 Skill 或自定义提示词的 AI 工具中并启用即可。

## 4. 使用方法

向加载该 Skill 的 AI 助手提供人物参考图，并说明需要的视图和画面要求。

```text
提取参考图中的人物，只要正面和背面，横向 16:9，纯灰色影棚背景，4K 高清。
```

可用视图：正面、侧面、背面、正脸特写。若输入“只要正背面，不要侧面，也不要脸部特写”，Skill 会输出二宫格，不会增加其他视图。

## 5. 输入输出示例

### 示例一：三宫格

输入：

```text
提取人物，制作横向 16:9 三宫格，依次展示正面、背面和正脸面向镜头的脸部特写，4K 高清，纯灰影棚背景。
```

输出：

```text
提取参考图中的人物主体，保持人物身份、脸部特征、发型、服装、配饰、色彩与材质完全一致，制作横向 16:9 三宫格角色设定图。三个等宽区域依次展示人物正面全身像、背面全身像、正脸面向镜头的头肩部面部特写。视图之间保留均匀灰色间距，避免拥挤；统一人物比例、服装、发型、配饰和光线。纯净中性灰色影棚背景，无道具、无文字、无 Logo、无水印。4K 超高清，清晰锐利，准确人体结构，真实皮肤与织物纹理。
```

### 示例二：二宫格

输入：

```text
只要人物正面和背面，不要侧面，不要脸部特写。
```

输出：

```text
横向 16:9 二宫格，仅展示人物正面全身像与背面全身像，不添加侧面或脸部特写；保持人物身份、服装、发型和配饰一致，使用纯灰影棚背景，4K 高清，无文字和水印。
```
