# TestSkill

## 适用场景

当用户提供一个视频构想、分镜草稿、故事片段或拍摄要求时，使用本 Skill 将其转换为可直接提交给 AI 视频生成模型的高准确度提示词。

本 Skill 重点优化：叙事目标与情绪变化、主体行为与动作连续性、镜头景别与构图、摄影机运动、灯光方向与明暗关系、对焦与曝光、时间顺序、声音、以及负面约束。

## 明确排除

除非用户明确要求，否则不要加入：

- 人物外貌、脸部、发型、体型、肤色、年龄等外观描述；
- 服装款式、颜色、材质等人物外观描述；
- 场景建筑、空间装饰、背景布置等外观描述；
- 道具的颜色、材质、造型、品牌等外观描述；
- 依赖后期剪辑、调色、特效合成或剪辑软件才能实现的内容。

可以描述主体的身份、位置、动作、关系、朝向和情绪，但不要描述其外观。

## 核心工作流程

### 1. 解析输入

提取视频主题、叙事目的、主体关系、动作顺序、空间关系、情绪变化、镜头类型、机位运动、灯光、声音、时长、画幅和平台要求。

将信息分为：

1. **已知要求**：用户明确提供的内容；
2. **必要补全**：为了让模型准确生成而必须补充的内容；
3. **不可擅自决定**：会改变故事、人物设定或用户意图的内容。

### 2. 处理缺失信息

可采用以下低风险默认值：

- 未指定时长：8 秒；
- 未指定帧率：24fps；
- 未指定镜头语言：自然、克制、连续的单段镜头；
- 未指定摄影机运动：缓慢、稳定且有明确动机的运动；
- 未指定对白：不添加对白；
- 未指定声音：保留与动作匹配的现场环境声；
- 未指定画幅：16:9；
- 未指定风格：写实、电影感、物理可信。

若缺失信息会显著改变结果，列出待确认项，同时提供采用默认值的可用版本，不要强行编造。

### 3. 设计可生成的镜头

单段视频优先采用一个清晰的连续镜头。每个镜头明确：开始状态、主体位置和朝向、一个主要动作、摄影机如何响应、光线如何保持连续、结束状态。

使用可观察的动词，例如：走近、停下、抬头、转身、伸手、拿起、放下、回望、坐下、缓慢后退。避免只使用“高级”“很电影”等不可执行的抽象词。

### 4. 控制时间与连续性

使用明确时间轴，例如：0–2 秒建立状态，2–5 秒完成主要动作，5–8 秒保持结果和情绪。每段只安排少量动作，确保主体数量、动作方向、视线、空间位置和光线逻辑连续。

### 5. 生成提示词

默认输出：

1. **可直接生成的视频提示词**；
2. **负面提示词**；
3. **参数建议**；
4. **待确认项**；
5. **复杂需求的拆镜建议**。

## 提示词结构

```text
[视频目标与整体情绪]
[时长、画幅、帧率]
[主体、位置、朝向和初始状态]
[按时间顺序描述动作]
[景别、构图、视线和空间关系]
[摄影机运动、速度和稳定方式]
[灯光方向、明暗关系、色温和连续性]
[对焦、景深、曝光和运动模糊]
[现场声音、对白或静默]
[结尾状态和生成约束]
```

## 写作规则

- 使用具体、可视化、可执行的描述；
- 一句话只表达一个主要控制意图；
- 先描述主体动作，再描述摄影机反应；
- 用“保持”“始终”“连续”“不要切换”控制一致性；
- 正向指令与负面提示词配合；
- 不擅自加入外观、品牌、字幕或对白；
- 对复杂需求主动降低镜头数量和动作密度。

## 负面提示词模板

按实际需求选择必要项目：

```text
不要改变主体数量，不要新增或删除主体，不要出现重复主体，不要肢体变形，不要动作跳变，不要突然改变方向，不要镜头瞬移，不要无理由变焦，不要画面闪烁，不要曝光忽明忽暗，不要光线方向跳变，不要焦点来回 hunting，不要背景突然变化，不要不必要的镜头切换，不要字幕，不要水印，不要品牌标识，不要未要求的对白，不要夸张表演，不要卡通化，不要画面抖动。
```

## 复杂输入判断

- 简单动作：一个连续镜头；
- 两个连续动作：使用时间轴，每段一个核心动作；
- 多个地点或时间跳转：建议拆成多个视频片段；
- 多主体交互：明确各主体位置、动作顺序和视线，不使用模糊的“他们互动”；
- 精确对白或文字：提醒视频模型可能生成不稳定；
- 用户只说“电影感”：具体化为稳定镜头、明确光线方向、自然运动模糊、克制表演、连续空间关系和真实声音，不额外加入外观风格。

## 安全与质量边界

- 不生成侵犯隐私、冒充真实人物或未经授权复制在世创作者独特风格的提示词；
- 不输出真实个人敏感信息；
- 对危险、违法或高风险行为保持必要的安全距离；
- 只修改提示词，不把未获授权的内容写入项目文件；
- 用户当前明确要求与“排除外观”规则冲突时，以用户当前要求为准，并说明调整范围。
