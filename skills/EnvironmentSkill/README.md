# Image Prompt Optimizer

一个开源、可复用、模型无关的 AI 生图提示词优化 environmentSkill。它将自然语言创意整理成清晰、可执行、可复制的图像生成提示词。

## 特性

- 将一句话创意扩展为结构化生图提示词。
- 默认横屏 `16:9`、`4K/UHD`、高清细节。
- 默认采用原创角色、原创场景和通用视觉属性。
- 避免直接复制受保护角色、品牌 Logo、现有作品或在世艺术家个人风格。
- 输出主提示词、负面提示词、建议参数、假设与合规检查。
- 不绑定特定图像模型、厂商、API 或操作系统。
- 支持一宫格、二宫格、三宫格、四宫格和九宫格的多视图场景扩写。
- 自动保持多宫格之间的主体、服装、道具、环境和色彩一致性。
- 默认输出精炼、可直接复制的提示词，避免冗长解释和同义词堆叠。
- 复杂宫格任务按需展开，普通任务优先保持短小。

## 使用方式

将 `SKILL.md` 作为系统提示词、技能文件或项目规则加载，然后直接输入自然语言需求，例如：

> 帮我做一张未来海滨生态城市的图，要有海、有绿色建筑，电影感。

Skill 会输出：

1. 可直接复制的精炼主提示词；
2. 与主题相关的精简负面提示词；
3. 画幅、风格和构图建议；
4. 关键假设与待确认项；
5. 原创与版权安全说明。

## 简洁输出

默认采用“信息完整但不冗长”的输出方式：

- 普通主提示词建议约 60–140 字；复杂场景最多约 220 字。
- 宫格主提示词建议每格 12–35 字，总长度通常不超过 280 字。
- 每个视觉要素只表达一次，合并重复的高清、细节、清晰等词语。
- 负面提示词通常保留 8–18 个与主题相关的限制词。
- 除非用户要求详细版、电影分镜版或完整设定版，否则不输出长篇解释。

## 默认输出约定

```yaml
orientation: landscape
aspect_ratio: "16:9"
resolution: "4K UHD"
originality: required
copyright_safety: required
model_specific_parameters: omitted
```

“4K”是目标输出规格，不代表所有平台都会原生生成 `3840×2160`。如果目标平台需要独立的尺寸或放大步骤，应将其作为平台适配建议，而不是写死在核心提示词中。

## 输入内容

可以直接输入自然语言，也可以提供以下信息：

- 主题与用途
- 主体、动作和主体关系
- 环境、时间、天气和季节
- 构图、视角、镜头和景深
- 光线、色彩、材质和氛围
- 风格方向，例如写实、3D、商业摄影、手绘或电影感
- 文字需求、禁用元素和目标模型

字段缺失时，Skill 会采用透明、克制的默认值，并在输出中标注。只有会显著影响结果的信息缺失时，才提出最多 3 个澄清问题。

## 宫格视图扩写

当输入包含“一宫格、二宫格、三宫格、四宫格或九宫格”时，Skill 会自动把每个宫格扩写为独立视图，并保持主体设定和场景连续。

默认规则如下：

- 一宫格：主视图
- 二宫格：主视图；对象反向平视回望图
- 三宫格：主视图；对象反向平视回望图；45° 斜角全景视图
- 四宫格：主视图；对象反向平视回望图；45° 斜角全景视图；高位俯视或侧后方视图
- 九宫格：主视图、反向平视回望、45° 斜角全景、正侧面、侧后方/背面、低机位仰视、高位俯视、局部特写、远景收束图

每个宫格都会明确视角、景别、主体重点和空间关系。默认使用从左到右、从上到下的阅读顺序，并加入“清晰分隔、无重叠、无错位、无额外宫格”等约束。用户明确指定某个宫格内容时，以用户指定为准，只补全未指定部分。

示例输入：

> 生成一个三宫格，展示一座雾中山间木屋。

示例扩写方向：

> 三宫格画面：第一宫格为木屋主视图；第二宫格为反向平视回望图；第三宫格为 45° 斜角全景视图；三格保持同一建筑结构与色彩，清晰分隔，无重叠，横屏 16:9，4K UHD。



## 原创与合规原则

本项目不会帮助复制具体受保护作品。对于“某 IP 角色”“某品牌广告”“某电影截图”“某现有海报”或“某位在世艺术家风格”等输入，建议改写为：

- 原创角色与原创场景；
- 通用的时代、媒介、笔触、构图、色彩、光线和材质；
- 不含品牌 Logo、商标或可识别的现有 IP 元素；
- 不复刻任何具体作品或电影画面。

Skill 只说明“采用原创设计方向，降低侵权风险”，不承诺绝对不侵权。对于露骨色情、未成年人性化、极端血腥、仇恨或违法伤害内容，应拒绝或提供安全替代方案。
