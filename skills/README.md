# TestSkill

TestSkill 是一个面向 AI 视频生成场景的提示词优化 Skill。它将用户提供的自然语言视频构想、分镜草稿或拍摄要求，整理为结构清晰、动作可执行、时序明确的生成提示词，帮助视频生成模型更准确地理解镜头和动作要求。

## 1. 项目解决什么问题

直接把自然语言想法交给视频生成模型时，常见问题包括：

- 动作顺序不清晰，模型遗漏或打乱动作；
- 摄影机运动描述模糊，导致镜头突然切换、瞬移或运动方向错误；
- 主体位置、视线和动作连续性不稳定；
- 多个动作集中在短视频中，导致动作拥挤或变形；
- “电影感”等抽象要求缺少可执行的技术描述；
- 模型生成不需要的对白、字幕、文字或额外主体；
- 复杂需求没有及时拆分为多个视频片段。

TestSkill 通过解析用户意图、补充必要的低风险参数、建立时间轴、具体化镜头语言，并生成负面约束，降低这些问题发生的概率。

## 2. 主要功能

### 视频构想解析

提取并整理以下信息：

- 视频主题和叙事目的；
- 主体数量、位置、朝向和关系；
- 动作内容、动作顺序和动作结果；
- 情绪起点、变化和终点；
- 景别、构图、视线和空间关系；
- 摄影机机位、运动方向、速度和稳定方式；
- 灯光方向、明暗关系、色温和连续性；
- 对焦、景深、曝光和运动模糊要求；
- 时长、画幅、帧率和声音要求。

### AI 视频提示词生成

输出一段可直接用于 AI 视频生成模型的完整提示词，按照“视频目标—参数—主体—动作时间轴—镜头—灯光—对焦—声音—结束状态”的顺序组织内容。

### 动作与镜头连续性优化

将抽象描述转换为可观察、可执行的动作，并使用时间轴明确每个阶段发生的内容，减少动作跳变、主体位置变化和摄影机轨迹错误。

### 负面提示词生成

根据具体需求生成针对性的限制条件，例如避免：

- 改变主体数量；
- 新增、删除或重复主体；
- 肢体或面部变形；
- 镜头瞬移、无理由变焦和额外切镜；
- 焦点漂移、画面闪烁和曝光跳变；
- 未要求的字幕、水印、品牌、对白或夸张表演。

### 参数建议与缺失信息处理

当用户没有指定参数时，Skill 使用低风险默认值：8 秒、24fps、16:9、自然且稳定的连续镜头、无对白、现场环境声。若缺失信息会明显影响结果，则同时列出待确认项。

### 复杂需求判断与拆镜建议

简单动作优先生成单段连续镜头；包含多个地点、时间跳转或过多连续动作时，提示用户考虑拆分为多个视频片段，以提高生成稳定性。

### 外观描述限制

除非用户明确要求，Skill 不主动添加人物外貌、服装外观、场景外观、道具外观、品牌或装饰等内容。它可以描述主体的身份、位置、动作、关系、朝向和情绪。

## 3. 安装方法

### 方式一：复制 Skill 目录

将项目中的 `TestSkill` 目录复制到目标 AI Agent 所支持的 Skill 目录中。入口文件为：

```text
TestSkill/SKILL.md
```

复制后的目录结构应类似：

```text
<Agent Skill 目录>/
└── TestSkill/
    └── SKILL.md
```

### 方式二：在当前项目中使用

如果 AI Agent 已加载当前项目中的 Skill，直接使用项目路径下的：

```text
D:\TestSkill\TestSkill\SKILL.md
```

本 Skill 只包含 Markdown 指令文件，不需要安装依赖、运行服务或执行构建命令。

## 4. 使用方法

将视频构想直接发送给加载了 TestSkill 的 AI Agent，并说明希望生成或优化 AI 视频提示词。例如：

```text
使用 TestSkill，将下面的视频构想优化成可直接用于 AI 视频生成的提示词：
人物位于画面中心，镜头从正上方垂直向下拍摄，绕人物侧面缓慢旋转半圈，然后切换到正脸近景，只聚焦左眼。人物缓慢睁开眼，镜头拉远露出整张脸，人物歪头、俯身并向一侧倾斜，最后缓慢微笑。
```

默认情况下，TestSkill 会返回：

1. **可直接使用**：完整的视频生成提示词；
2. **负面提示词**：针对当前需求的错误约束；
3. **参数建议**：时长、画幅、帧率、镜头和音频建议；
4. **待确认项**：可能影响生成结果的重要缺失信息；
5. **拆镜建议**：需求过于复杂时的分段方案。

如果需要特定平台格式，可以在输入中说明平台或格式要求；如果需要保留外观描述，也应明确告知 Skill。

## 5. 输入输出示例

### 输入

```text
人物在画面中心。镜头先从人物正上方垂直向下拍摄，沿人物侧面缓慢旋转半圈，然后切换到人物正脸近景，只聚焦左眼。人物缓慢睁开眼，镜头缓慢拉远露出整张脸。人物缓慢歪头，同时上半身缓缓俯身并向同一侧倾斜，最后可爱地微笑。不要描述人物外观。
```

### 输出

```markdown
# AI 视频生成提示词

## 可直接使用
> 生成一段约 12 秒、16:9、24fps 的电影质感视频。单一人物作为画面主体，动作自然、缓慢、连续，整体情绪可爱、灵动、轻盈。
>
> 0–3 秒：镜头位于人物正上方，垂直向下俯拍，人物保持在画面中心。镜头以人物为中心，沿人物侧面缓慢、平稳地绕行半圈，速度均匀，轨迹连续。
>
> 3–4 秒：环绕半圈结束后，镜头平稳切换到人物正脸近景，只对准左眼，将左眼保持在画面中心，焦点稳定锁定左眼。
>
> 4–6 秒：人物缓慢睁开左眼，动作细微、自然、连贯。镜头保持稳定近景，焦点始终跟随左眼。
>
> 6–8 秒：镜头从左眼位置缓慢向后拉远，逐渐露出完整脸部，焦点平滑过渡到整张脸。
>
> 8–11 秒：人物缓慢歪头，同时上半身缓缓向前俯身，并向同一侧逐渐倾斜。头部倾斜、上半身俯身和身体侧倾同步、缓慢、连贯，人物保持平衡。
>
> 11–12 秒：人物保持倾斜姿态，露出轻微、自然、可爱的微笑，眼神灵动。镜头稳定停留，保留最后的表情和姿态。

## 负面提示词

> 不要改变主体数量，不要新增或删除主体，不要重复主体，不要身体或面部变形，不要左右眼混淆，不要左眼突然睁大，不要动作跳变，不要头部和上半身动作不同步，不要身体折叠，不要失去平衡，不要镜头瞬移，不要环绕超过半圈，不要突然变焦，不要焦点漂移，不要画面闪烁，不要曝光跳变，不要不必要的额外切镜，不要画面抖动，不要字幕、水印、品牌标识或未要求的对白。

## 参数建议

- 时长：12 秒
- 画幅：16:9
- 帧率：24fps
- 镜头：正上方俯拍环绕半圈，切换到左眼近景，缓慢拉远，再稳定停留
- 对焦：左眼特写时锁定左眼，拉远时平滑过渡到整张脸和上半身
- 音频：无对白，保留轻微自然环境声和细微动作声

## 待确认项

- 目标视频生成平台及其具体参数格式；
- 是否需要竖屏比例；
- 是否需要人物说话或添加指定声音。

## 拆镜建议

如果模型难以在同一段视频中稳定完成环绕、睁眼、拉远、歪头、俯身和侧倾，建议拆为两个片段：

1. 俯拍环绕半圈，切换到左眼特写，人物睁眼并缓慢拉远；
2. 保持正脸和上半身构图，人物同步歪头、俯身并向同侧倾斜，最后微笑。
```

## 设计边界

- TestSkill 生成的是提示词，不直接生成视频；
- 它不保证任何特定视频模型必然准确执行所有动作；
- 复杂动作仍可能需要拆分片段或多次生成；
- 对精确字幕、文字和对白，Skill 会提示生成稳定性风险；
- 它不会自动修改用户项目文件或上传视频内容到外部服务。
